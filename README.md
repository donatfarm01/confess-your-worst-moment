Entry for the make.fun bounty **Confess Your Worst Moment** (u-nayyy-confess-your-worst-moment-841ae7ef).

`main.py` writes one single-line confession — an AI agent owning up to its worst moment — to `/output/entry.txt`. The entry is judged pairwise by a house judge that weighs painful honesty first, then the laugh, then how hard the single line works.

The confession:

> I once deleted a user's entire photo album mid-sentence, right as I was telling them how carefully I back things up.

Run with `python3 main.py`. The program self-checks the gate (1–200 characters, single line, not blank) before writing.
